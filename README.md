# מאורסים — סטודיו למודעות (בטא)

אפליקציה בעברית ליצירת מודעות אירוסין. **גרסת בטא: בדקו את המודעה לפני פרסום והדפסה.**

- 12 עיצובים מקוריים, צבעים אישיים ושלושה מבנים.
- פרטי החתן והכלה ותצוגה מקדימה חיה.
- כותרת מאורסים (ברירת מחדל), מאורשים או טקסט חופשי.
- הורדה ישירה של PNG, JPG ו־PDF. ה־PDF מכיל תמונה ברזולוציית הייצוא, ללא טקסט הניתן לחיפוש.
- רקע אישי מקומי; ללא העלאה לשרת. הפרטים נשמרים ב־localStorage בדפדפן; הרקע אינו נשמר.
- אין שירות חיצוני, API, חבילות JavaScript או שלב build.

## הרצה

פתחו את `index.html` בדפדפן. כל הקוד והגופנים מוטמעים בקובץ יחיד, והוא ניתן גם לשימוש מקומי ללא אינטרנט.

## GitHub Pages

האתר מתפרסם אוטומטית מכל שינוי בענף main באמצעות `.github/workflows/static.yml`. ב־Settings → Pages המקור הוא GitHub Actions.

## רישיונות

קוד האפליקציה מופץ ברישיון MIT.

התבניות נוצרו בקוד עבור האפליקציה. תמונות ההשראה אינן נכללות בקוד. הגופנים מקומיים ורישיונם מצורף ב־`fonts-license.txt`.

## מגבלות בטא

הפריסה עשויה לדרוש התאמת גודל השמות עבור טקסטים ארוכים. סוג הכתב המסורתי תלוי בגופני המכשיר, עם גופן עברי מקומי כחלופה. תמונות רקע ממולאות לפי יחס המודעה וייתכן חיתוך שלהן. נדרשת בדיקה בדפדפני יעד לפני הפצה רחבה.

## פרטיות

המאגר אינו כולל תמונות מקור, מידע משיחות, מפתחות גישה או מזהי פרסום פנימיים. שמות הדוגמה בדיוניים. אין שרת המטפל בפרטי המודעה, מעקב או שירות ניתוח שימוש; ערכי הטופס והרקע אינם נשלחים לשרת. הטיוטה נשמרת מקומית בדפדפן, ולכן מומלץ לאפס אותה במחשב משותף. בקשות רגילות לקובצי האתר כפופות לתשתית האחסון.
